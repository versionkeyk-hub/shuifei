本文件详细说明如何添加/修改农药数据、如何使用管理后台、如何更新网站。

快速入口：
网站地址：https://inspiring-kheer-4311c8.netlify.app/
管理后台：admin.html（用户名 admin，密码 nongyao2024）

一、两种添加数据的方式

你有两种方式添加新农药数据：

方式适合场景操作难度说明
方式A：管理后台添加少量农药（1-5条）简单网页操作，点击添加即可
方式B：直接编辑文件批量添加（10条以上）中等用文本编辑器打开JS文件，按格式添加

二、方式A：用管理后台添加

1打开管理后台

在网站底部点击"管理后台"链接，或在浏览器地址栏输入：你的网址/admin.html

2登录

用户名：admin　　密码：nongyao2024

如果要改密码，登录后点"修改密码"。

3添加农药

点"农药管理" → 点"添加新农药"按钮 → 填写表单 → 点保存。

表单各字段说明见下方数据格式说明。

4导出并更新网站

添加完所有新农药后，点"修改/导出数据"标签 → 选择"pesticides.js" → 可直接在文本框中编辑内容 → 点"下载当前文件"。

下载的文件替换掉网站中的 data/pesticides.js，然后把整个 pesticide-query-app 文件夹拖拽到 Netlify 即可更新网站。

也可以直接在"修改/导出数据"页面点"下载整个网站文件夹"按钮，一键打包下载全部文件。

注意：管理后台的数据保存在浏览器localStorage中，换浏览器或清除缓存会丢失。所以添加完一定要点"导出数据"下载文件。

三、方式B：直接编辑文件添加

3.1 打开数据文件

用任何文本编辑器（推荐 VS Code、Notepad++）打开：

pesticide-query-app/data/pesticides.js

3.2 找到添加位置

在文件中找到最后一个条目的结尾（},），在它后面、]; 前面添加新条目。

3.3 数据格式

每条农药数据的格式如下，照着抄就行：

{
  component: "农药成分名",           // 必填，农药有效成分的中文名
  aliases: ["别名1", "别名2"],       // 选填，商品名、英文名、缩写等
  category: "杀菌剂",               // 必填，从下方类别中选一个
  chemical_class: "三唑类",          // 选填，化学分类
  problems: "防治什么病",           // 选填，防治对象和病害
  usage: "参考：1500倍喷雾",        // 选填，用法用量
  precautions: "注意事项",          // 选填，使用注意事项
  brands: [                         // 选填，商品名和厂家
    {name: "商品名", company: "厂家名"}
  ],
  related: ["相关成分1"],           // 选填，复配中各单剂名
  flags: {                          // 选填，属性标记
    is_fungicide: true              // 是杀菌剂
  }
},

3.6 完整示例

假设要添加一个新农药"氟啶虫酰胺"：

  {
    component: "氟啶虫酰胺",
    aliases: ["Aria", "Gravita"],
    category: "杀虫剂",
    chemical_class: "吡啶酰胺类",
    problems: "防治蚜虫、飞虱、蓟马等刺吸式口器害虫",
    usage: "参考：2000-3000倍叶面喷雾（具体以产品标签为准）",
    precautions: "对家蚕有毒，桑园附近慎用",
    brands: [
      {name: "Aria", company: "日本石原"},
      {name: "氟啶虫酰胺", company: "国内多家"}
    ],
    related: [],
    flags: {is_insecticide: true}
  },
重要提醒：
  1. 每条数据结尾要有逗号 ,
  2. 最后一条例外——在 ]; 前面的那条不要加逗号
  3. 中文引号和英文引号不要混用，统一用英文引号
  4. component 是主键，不能重复

四、如何更新到线上网站

简单来说：改完文件 → 把整个 pesticide-query-app 文件夹拖到 Netlify → 完成。

你的网站部署在 Netlify（地址：https://inspiring-kheer-4311c8.netlify.app/），更新方式就是拖拽上传。

关于 Gitee：Gitee 仓库（gitee.com/huiminhaotian/pesticide-query）只是代码备份，和 Netlify 没有自动连接。你不需要管 Gitee，平时只用 Netlify 拖拽更新就行。Gitee 的作用是万一需要找回历史版本时有个备份。
1修改文件

在 data/pesticides.js 中添加/修改数据（或用管理后台导出新文件替换）。

2拖拽到 Netlify 更新
  1. 登录 Netlify
  2. 进入你的站点（inspiring-kheer-4311c8）
  3. 点 "Deploys" → 拖拽区域 "Drag and drop your site output folder here"
  4. 把整个 pesticide-query-app 文件夹拖进去
  5. 等待几秒，部署完成

或者：在管理后台点"修改/导出数据" → 点"下载整个网站文件夹"按钮，下载 zip 解压后拖到 Netlify。

3验证

访问 https://inspiring-kheer-4311c8.netlify.app/，按 Ctrl+F5 强制刷新。

七、常见问题

Q: 添加数据后网站没变化？

A: 确认已把整个 pesticide-query-app 文件夹拖拽到 Netlify，等待几秒后刷新浏览器（Ctrl+F5 强制刷新）。

Q: 网页打不开或报错？

A: 检查 pesticides.js 文件格式：每条数据有没有少逗号、有没有引号不匹配。可以用浏览器打开 index.html，按 F12 看 Console 有没有报错。

Q: 搜索不到新加的农药？

A: 搜索会匹配 component、aliases、brands、related 四个字段。确认你添加的农药名称没有错别字。也可以试试用别名搜索。

Q: 管理后台数据丢了？

A: 管理后台数据存在浏览器 localStorage 中，清缓存会丢。务必在添加完数据后点"导出数据"下载文件。

Q: 想修改管理后台密码？

A: 登录后点"修改密码"，输入旧密码和新密码即可。密码存在浏览器中，换浏览器需要重新输入默认密码 nongyao2024。
