# 农药混配查询应用 - 维护与部署指南

## 一、应用文件结构

```
pesticide-query-app/
├── index.html        ← 页面结构（一般不用改）
├── style.css         ← 样式（一般不用改）
├── app.js            ← 搜索和混配逻辑（一般不用改）
└── data/
    ├── pesticides.js ← 农药数据库（你要改这个）
    └── products.js   ← 公司产品数据库（加新产品时改这个）
```

## 二、怎么改农药数据

打开 `data/pesticides.js`，照着已有条目的格式增删改。每个条目长这样：

```javascript
{
  component: "成分名",           // 必填，如"多菌灵"
  aliases: ["别名1", "别名2"],   // 可选，常见叫法
  category: "杀菌剂",            // 必填：杀菌剂/杀虫剂/调节剂/除草剂/助剂/肥料
  chemical_class: "苯并咪唑类",  // 可选，化学分类
  problems: "防治什么病",        // 必填，一句话说清楚
  usage: "500-1000倍叶喷",      // 可选，常见用法
  precautions: "注意事项",       // 可选
  brands: [                      // 可选，品牌商品
    { name: "品牌名", company: "公司名" }
  ],
  related: ["关联成分名"],       // 可选，搜这个成分也能搜到本条目
  flags: {                       // 决定混配判断，最关键
    is_copper: false,       // 铜制剂（一律禁混所有产品）
    is_heavy_metal: false,  // 含重金属（一律禁混）
    is_herbicide: false,    // 除草剂（一律禁混）
    is_strong_acid: false,  // 强酸性pH<3（一律禁混）
    is_strong_base: false,  // 强碱性pH>10（一律禁混）
    is_fungicide: false,    // 杀菌剂（与傲生/傲净禁混）
    is_acidic: false,       // 偏酸性（与偏碱性产品需间隔）
    is_basic: false,        // 偏碱性（与偏酸性产品需间隔）
    has_calcium: false,     // 含钙（与含磷产品需间隔）
    has_phosphorus: false,  // 含磷（与含钙产品需间隔）
    is_humic_acid: false    // 含腐殖酸（与含钙产品需间隔）
  }
}
```

### flags 怎么填

| 场景 | flags 设置 | 效果 |
|------|-----------|------|
| 铜制剂（氢氧化铜、波尔多液） | is_copper: true | 与全部16个公司产品禁混 |
| 除草剂（草甘膦、草铵膦） | is_herbicide: true | 与全部16个公司产品禁混 |
| 强碱性（石硫合剂） | is_strong_base: true | 与全部16个公司产品禁混 |
| 杀菌剂（多菌灵、嘧菌酯） | is_fungicide: true | 与傲生、傲净禁混，其余可混 |
| 偏碱性农药（王铜） | is_basic: true | 与酸性产品（黑岩/傲叶/傲蕾/傲岚）需间隔7天 |
| 含钙肥料（硝酸钙、糖醇钙） | has_calcium: true | 与含磷产品（傲岚/果大夫）需间隔2-3天 |
| 含磷肥料（磷酸二氢钾） | has_phosphorus: true | 与含钙产品（傲果/均施/傲土）需间隔2-3天 |
| 一般杀虫剂（阿维菌素、吡虫啉） | is_acidic: true | 与全部公司产品可混（无偏碱性产品冲突） |
| 中性农药/助剂 | flags: {} 留空 | 与全部公司产品可混 |

### 添加新条目

在 `data/pesticides.js` 的数组末尾，照着格式加一个 `{}` 块就行。逗号别漏。

### 删除条目

找到对应条目，整块删掉。别把逗号搞乱。

## 三、怎么改公司产品数据

打开 `data/products.js`，照着已有条目格式加新产品。flags 决定这个产品会被哪些农药规则触发：

```javascript
{
  name: "产品名",
  category: "产品类别",
  description: "一句话描述",
  usage: "用法",
  flags: {
    is_microbial: false,      // 微生物菌剂（与杀菌剂禁混）
    is_calcium: false,       // 含钙（与含磷/腐殖酸产品需间隔）
    is_phosphorus: false,    // 含磷（与含钙产品需间隔）
    is_acidic: false,        // 偏酸性
    is_humic_acid: false,    // 含腐殖酸（与含钙产品需间隔）
    is_high_cost_foliar: false, // 高端叶面肥（禁止冲施）
    is_root_fertilizer: false   // 根际肥
  }
}
```

## 四、部署到 Gitee Pages（一次设置）

### 第1步：注册 Gitee 账号
1. 打开 https://gitee.com
2. 注册账号（手机号即可）
3. 完成实名认证（上传身份证，几分钟通过）

### 第2步：创建仓库
1. 登录后点右上角"+"→"新建仓库"
2. 仓库名填：`pesticide-query`
3. 选"公开"
4. 勾选"初始化仓库"（选不选都行）
5. 点"创建"

### 第3步：上传文件
1. 进入仓库页面
2. 点"上传文件"按钮
3. 把 pesticide-query-app 文件夹里的全部5个文件（index.html、style.css、app.js、data/pesticides.js、data/products.js）拖进去
4. 注意：data 文件夹里的文件要放在 data/ 目录下（Gitee 上传时建子文件夹）
5. 点"提交"

> 如果 Gitee 上传不支持子文件夹，可以先把整个文件夹打个 zip 上传，或者逐个文件在网页上建。

### 第4步：开启 Gitee Pages
1. 进入仓库 → 点顶部"服务"→"Gitee Pages"
2. 部署分支选 `master`，目录选 `/`
3. 点"启动"
4. 等待1分钟，会给你一个网址，类似：`https://yourname.gitee.io/pesticide-query`

### 第5步：给客服用
1. 把上面那个网址发给客服
2. 客服在电脑桌面右键→新建→快捷方式，粘贴网址
3. 双击快捷方式即可打开

## 五、以后怎么更新数据（不用找我）

### 方式一：在 Gitee 网页上直接改（最简单）
1. 登录 Gitee → 进入 pesticide-query 仓库
2. 点击 `data/pesticides.js`
3. 点右上角"编辑"按钮
4. 在网页编辑器里改文字（照着已有格式）
5. 点"提交修改"
6. 等1分钟，线上自动更新

### 方式二：本地改完批量上传
1. 在本地电脑改 `data/pesticides.js` 文件（用记事本或VSCode）
2. 登录 Gitee → 进入仓库
3. 点"上传文件"→上传修改后的 `pesticides.js`
4. 提交后线上自动更新

### 方式三：让AI帮你加（找我就行）
把要加的农药名和基本信息发给我，我帮你生成条目代码，你粘贴进 pesticides.js 即可。

## 六、注意事项

1. **改完保存后要确认**：打开线上网址，搜一个新加的农药，确认能搜到、混配结果正确
2. **flags 别填错**：is_copper 和 is_herbicide 填错了会导致全线禁混，影响很大
3. **备份**：改之前先在本地存一份当前的 pesticides.js 作为备份
4. **编码**：文件必须用 UTF-8 编码保存（记事本默认就是）
